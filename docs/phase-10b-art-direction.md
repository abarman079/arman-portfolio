# Phase 10B art-direction decisions

Decision date: 2026-08-25

- Featured archive projects now use large, asymmetric evidence-led compositions: a model-comparison chart, a real Power BI dashboard, and a research trade-off chart. Titles, summaries, technical facts, and source links remain visible without hover.
- Additional archive projects use compact editorial rows with one real left-aligned visual each. The five images come from verified deployments, locally run repository applications, or the custom EduConsult plugin source.
- Archive hover and focus treatments use a restrained image scale and row-color shift. Touch layouts retain every title, summary, stack, and action with no pointer-dependent information.
- The About mosaic remains unchanged structurally; only public-facing prose was made more direct and less process-oriented.
- The Contact section no longer displays a decorative empty rectangle. A configured environment renders the secure form; an unconfigured production environment renders a complete direct-email panel instead of a disabled form or development message.
- Public copy now speaks directly about the work. Internal evidence validation and provenance language remain in code/tests/docs, where they belong.
- Hero, Selected Work, Capability 3D, flagship compositions, case studies, and motion ownership were intentionally preserved.
- No dependency, new animation loop, generated visual, external image, or custom technical cover was introduced.
